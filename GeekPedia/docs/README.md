# Geekpedia - Sistema de Recomendação por Grafos

Projeto desenvolvido para a disciplina de Teoria dos Grafos. O **Geekpedia** é um sistema de recomendação de entretenimento digital (animes, jogos, filmes) que utiliza grafos ponderados para encontrar conexões e caminhos inteligentes entre diferentes mídias e franquias.

## Como Executar o Projeto

**Pré-requisitos:**
* Python 3.10 ou superior instalado na máquina.

**Instalação:**
O sistema foi construído utilizando apenas bibliotecas nativas do Python (`json`, `collections`, `heapq`). Não é necessária a instalação de pacotes externos.

```bash
# 1. Clone o repositório
git clone [https://github.com/Nickx67/GEEKPEDIA-projeto-Nicolas-Silva.git](https://github.com/Nickx67/GEEKPEDIA-projeto-Nicolas-Silva.git)

# 2. Entre na pasta do projeto
cd GEEKPEDIA-projeto-Nicolas-Silva/GeekPedia

Execução:

# Execute o arquivo principal a partir da raiz da pasta GeekPedia
python src/main.py

Saída esperada:

===== GEEKPEDIA =====

1 - Recomendações Diretas (BFS)
2 - Caminho Inteligente (Dijkstra)
0 - Sair

Escolha uma opção:
